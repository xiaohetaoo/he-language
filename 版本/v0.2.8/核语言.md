## 一、项目是什么

「核语言」（He Language）= 一门**中文编程语言**，源文件后缀 `.xht`。

- **实现方式**：不做独立解释器，而是把 `.xht` 逐字符转译成 Python 源码再交给 Python 执行。
  转译只做等长替换（全角符号→半角、`核说`→`print` 等），**行号不变**，报错行号与原文一一对应。
- **组成**：内核（命令行 + 交互模式）+ 图形界面「核工坊」（PyCharm 新 UI 风格，PySide6/Qt）。
- **依赖**：内核只用 Python 标准库；只有界面用 PySide6。
- **仓库**：`xiaohetaoo/he-language`（远程 `origin`，SSH）。
- **许可**：MIT。

## 三、必须遵守的约定

### 3.1 权限类（硬约束）

1. **push / 打 tag / 发 Release 前必须先问用户。**
   「做某个功能」「审查代码升版本」只授权写代码、跑测试、**本地**提交，不包含这三件事。
   本地 `git add` / `git commit` 可以自由做，但提交前要让用户看清改了哪些文件、提交信息是什么。
2. **删除文件前先说明理由并取得确认。**
3. **任何上传到网络的操作都要经用户同意**，且上传前检查有无隐私文件、冗余文件。
4. `桌面/09_校庆.xht` 是私人内容，**绝不上传 GitHub**。

### 3.2 工作方式类

5. **不往工作区外放文件**；临时文件每轮清理。产物与中间文件都留在 `D:\dsh\dsh5`。
6. **本文件（`核语言.md`）每轮更新**：记录当轮做了什么、结论、待办变化。
7. **工具或功能坏了、解决不了，要向用户报告**，不要静默绕过。
8. **不要默认用户什么都会**：专业术语第一次出现要解释（如「回归测试」「归档」「tag/Release」）。
9. 界面要像 PyCharm；代码要**全部审查**、功能要**全部测过**（用户明确要求）。
10. 准确性优先：不凭猜测下结论；判断界面是否正常要在进程内读真实状态，不能只看截图。

## 六、常用命令

```powershell
py -3 测试/跑全部.py        # 全量回归 25 项（改动后必跑；打包前自动调用）
py -3 测试/自测.py          # 内核 35 条 unittest
py -3 测试/自测Qt.py        # Qt 功能 102 条断言
py -3 测试/逐项验证Qt.py    # 菜单/开关/对话框 49 条
py -3 测试/归档版本.py      # 归档到 版本/vX.Y.Z/
py -3 测试/打包Qt.py        # 出 exe（约 105 MB，自动自检）
py -3 测试/发布Release.py   # 建 Release 并上传 exe（需 GH_TOKEN）
```

术语：**全量回归** = 一次跑完全部测试集，确认改动没弄坏旧功能；
**归档** = 把当前源码完整复制一份到 `版本/vX.Y.Z/` 作快照；
**tag** = git 打在某个提交上的版本标签；**Release** = GitHub 上的发布页（可挂 exe 附件）。

## 七、发布流程（每一步先问用户）

1. 改代码 → 2. 改 `核.py` 的 `版本` → 3. `测试/归档版本.py`（同版本内再改 bug 用 `--覆盖`）
→ 4. `版本记录.md` 补一行 + 写「## X.Y.Z 发布说明」→ 5. `测试/打包Qt.py`
→ 6. push main + push tag → 7. `测试/发布Release.py`。

要点：附件名必须纯 ASCII（中文名会存成 `default.exe`）；107 MB 必须流式上传；
`api.github.com` 多数 IP 被墙，脚本已内置多 IP 直连（`HE_DIRECT=1`）；
`--add-data` 目标目录要写 `"素材;素材"` 不能 `"素材;."`；Qt 打包必须 `--collect-all PySide6`。

## 八、高频坑（完整表见 `项目状态.md`）

| 现象 | 根因 |
| --- | --- |
| QSS 报 Could not parse stylesheet | Qt 不认中文 objectName，也不处理中文注释 |
| 折叠状态一重高亮就丢 | `userState` 被 QSyntaxHighlighter 占用，折叠标记须存 `QTextBlockUserData` |
| 打包报「返回码 1」但脚本没问题 | 孤儿进程锁住 exe；单文件 exe 是两层，必须 `taskkill /T /F` 杀整棵树 |
| 打包版 exe 点「运行」打开的是界面 | 打包入口缺 `--内核` 分支（已修，注意别再丢） |
| 高亮与翻译对「核核紧贴」判断相反 | 两边词边界口径必须共用 `核.词左界/词右界` |
| `~Qt.ShiftModifier` 在 PySide6 取不到 Ctrl | `ControlModifier` 在枚举掩码外，要转 int 做位运算 |
| 回归跑完示例文件被改 | 测试里对从例子目录打开的文档按了保存；现已用临时副本 + 源码树指纹闸 |
| 改文档要等回归跑完 | 指纹闸分不清「测试写脏」和「人在同时改」，会误报 |
