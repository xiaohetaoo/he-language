# 核语言 ↔ Python 对照表

> **「核语言」一栏留空的，就是还没定义的写法**，想好中文名后填进空格即可。
> 填完把对应关系补进 `核.py` 的 `关键词表` / `函数表` / `方法表` / `参数表`，
> 再运行 `python 测试/自检对照表.py` 验证有无重名。

本表由 `python 测试/生成对照表.py` 自动生成，数据取自 `核.py`。

## 怎么填

1. 在「核语言」栏写下中文名，例如把空着的 `sum` 填成 `核求和`
2. 把这一行补进 `核.py` 对应的表（`函数表` / `方法表` / …）
3. 运行 `python 测试/自检对照表.py` 检查有没有重名或冲突
4. 再运行 `python 测试/生成对照表.py` 刷新本表

**命名惯例**（照现有风格起名，读起来才统一）：

| 类别 | 前缀 | 现有例子 |
| --- | --- | --- |
| 关键字 | `核` | `核若` `核定义` `核返回` |
| 内置函数 | `核` / `说核` | `核长度` `核最大` `说核` |
| 方法 | `核` | `核加入` `核排序` `木亥` |
| 关键字参数 | `核` | `核尾` `核隔` |

> 注意：方法只在 `.` 之后生效，所以方法名可以与函数名重复；
> 关键字不能与已有中文名重复，否则自检会报错。
