# 核语言 版本记录

每个版本都完整归档在 `版本/` 目录，可随时回看或对比。

版本号从 **0.0.1** 起，遵循 `主版本.次版本.修订号`：

- **主版本**：语言语法或运行方式有不兼容变化
- **次版本**：新增成体系的功能（如新的对照表大类、新的界面模块）
- **修订号**：修 bug、调样式、改文档

## 发布流程

```
1. 改代码
2. 把 核.py 里的 版本 改成新版本号
3. python 测试/归档版本.py     核核 归档到 版本/vX.Y.Z/
4. 在下面的表里补一行
5. python 测试/打包.py          核核 重新出 exe
```

查看已归档版本：

```
python 测试/归档版本.py --列表
```

界面里也可以看：**帮助 → 版本历史**。

## 0.0.1 详细说明

**语言**

- 中英文符号视同：代码区全角标点自动归一，字符串与注释内容保持原样
- 中文弯引号 `“ ” ‘ ’ 「 」 『 』` 当普通引号处理
- 关键字 36 个（规则表 14 个 + 补齐 22 个）
- 内置函数 15 个、字符串/列表/字典方法 26 个、关键字参数 2 个
- `核"…"` 为 f 字符串，花括号内可用中文名，`{x:.2f}` 等格式原样保留
- 未定义清单：对照表里没有的英文写法原样执行，并累积记录到 `未定义.txt`

**工具**

- 命令行：运行 / 检查 / 转译 / 报告 / 交互模式
- 图形界面「核工坊」：项目树、圆角标签页、语法对照表、运行窗口、状态栏
- 拖放：`.xht` 拖进窗口即打开，文件夹拖入即切换项目
- 打包：PyInstaller 单文件 exe，内置内核，目标机器无需 Python

**测试**

- 内核自测 25 项
- 界面自测 66 项

**界面（重做）**

- 配色重做：层次分明（窗口/编辑器/面板三档），深色浅色各 44 个色键
- 圆角：窗口用 Win11 原生圆角，工具栏按钮与标签页用 Canvas 绘制圆角
- 标题栏图标改为核语言图标（此前因 withdraw 状态下设置而失效）
- 新增独立**设置窗口**（`Ctrl+,`）：外观 / 编辑器 / 运行 / 关于 四页
- 功能去重：运行与停止原来在四处重复，现收敛为主工具条 + 快捷键
- 左侧竖条只留面板开关；运行窗口工具条精简为三个按钮
- 修复隐藏面板后残留空白（grid minsize 未归零）

**代码审查修复（同一版本内）**

- 不带换行的提示语（如「请输入：」）此前要等到换行才显示，界面看似卡死 → 改为非阻塞读取
- 运行中关闭文件会留下无人管理的子进程 → 关闭前先停止
- 打开文件夹会弹出模态错误框并阻塞 → 改为状态栏提示
- 子进程管道未关闭导致句柄泄漏 → 运行结束/停止/退出时统一收尾
- 带 BOM 的源文件编译失败 → 转译入口剥离 BOM
- 未定义清单「出现次数」不准确（同文件多次出现只记 1）→ 改为真实计数
- 圆角图助手在负数半径时抛异常 → 钳制半径
- 清理死代码：未使用的缩进画布、废弃的画线方法
- 图标缓存按根窗口隔离（此前连续开关窗口会报 image doesn't exist）
- 窗口关闭时取消残留定时任务，避免销毁后报 invalid command name
- 打开不存在的文件不再弹模态框（自动化场景下会永久阻塞）
- 欢迎页居中改用 grid（此前 place 相对定位会被项目树挤偏，内容跑出可视区）
- 图标分尺寸 PNG 曾缺失导致 titlebar 回落成系统默认图标；打包脚本现会自动补齐
