# 核语言 版本记录

每个版本都完整归档在 `版本/` 目录，可随时回看或对比。

版本号从 **0.0.1** 起，遵循 `主版本.次版本.修订号`：

- **主版本**：语言语法或运行方式有不兼容变化
- **次版本**：新增成体系的功能（如新的对照表大类、新的界面模块）
- **修订号**：修 bug、调样式、改文档

## 发布流程

```
1. 改代码
2. 把 核.py 里的 版本 改成新版本号
3. python 测试/归档版本.py     核核 归档到 版本/vX.Y.Z/
4. 在下面的表里补一行
5. python 测试/打包.py          核核 重新出 exe（会自动跑自检）
6. python 测试/发布Release.py   核核 创建 Release 并上传 exe
```

> 发布 Release 需要 Personal Access Token（Contents 读写权限）。
> 只用 SSH 密钥只能 push 代码，不能上传 Release 附件。

查看已归档版本：

```
python 测试/归档版本.py --列表
```

界面里也可以看：**帮助 → 版本历史**。

## 0.0.6 详细说明

**界面迁移到 PySide6（Qt）—— 本次最大改动**

原因：tkinter 维护成本太高。旧版界面 4462 行里有 101 处手动 `configure(bg=)`、
28 处 Canvas 手绘圆角、还要用 ctypes 改窗口样式。换 Qt 后：

| 项目 | tkinter 版 | Qt 版 |
| --- | --- | --- |
| 界面代码 | 4462 行 | 2356 行（少 47%） |
| 换主题 | 101 处逐控件改色 | **一份 QSS，一行调用** |
| 圆角 | Canvas 手绘 | `border-radius` 一行 |
| 无边框窗口 | ctypes 改窗口样式 | `FramelessWindowHint` |
| 高 DPI | 文字发虚 | 自动适配，锐利 |
| 滚动条 | 需绕开 ttk 黑块 | 原生自适应 |

新增文件（与 tkinter 版并存，可回退）：
- `主题.py`：色表 + QSS 模板，深浅两套主题的唯一来源
- `编辑器.py`：行号、语法高亮、当前行、缩进参考线、自动缩进、注释切换、查找替换
- `核工坊Qt.py`：主窗口（顶部单行 + 左竖条 + 三栏 + 运行窗口 + 状态栏）
- `设置窗口Qt.py`：设置对话框四页
- `查找对话框.py`：查找替换 + 转到行
- `配置.py`：配置持久化（打包版存 `%APPDATA%/核工坊`）
- `测试/打包Qt.py`、`测试/自测Qt.py`

界面细节（对齐 PyCharm 新 UI）：
- 顶部单行：图标 + ☰ 菜单 + 项目名 + 版本控制 + ▶ 运行 + ⚙ + 搜索 + 窗口按钮
- 左侧竖条：项目 / 结构 / 运行 / 设置，带运行状态点
- 标签页圆角 + 选中底部蓝条；未保存显示 ●
- 缩进参考线按行绘制（只在这行有缩进时画一小段），不再通顶
- 窗口尺寸与位置记忆

新增功能：
- 查找 / 替换（Ctrl+F）、转到行（Ctrl+G）
- 自动配对括号与引号，选中文字时自动包裹
- 智能退格：删掉左括号时连带删右括号
- 最近打开文件菜单
- 状态栏显示行/列与选中字数
- 拖放：.xht 拖入即打开，文件夹拖入即切换项目

**测试**：Qt 功能自测 30 项、内核自测 25 项，全部通过
**打包**：`dist/核工坊Qt.exe` 约 107 MB，自带 Qt 运行库，目标机器无需装 Python

**其它**

## 0.0.4 详细说明

**字符串引号修复（审查发现）**

- 字符串内容里的 `「」` `『』` 曾被悄悄改写成 `"`，与「字符串内容保持原样」
  的承诺相违。原因是收尾判断用了 NFKC 归一后的字符，而 `「` 归一后正是 `"`，
  于是文内引用符号被当成结束引号。现改为只看原字符是否与起始引号配对。

**异常类型中文化**

- 新增 `异常表`：`除零错误`→`ZeroDivisionError`、`值错误`→`ValueError`
  `下标错误`→`IndexError`、`键错误`→`KeyError`、`类型错误`→`TypeError` 等 22 条
- 仅在 `核异常` / `核抛出` 之后生效，别处写同名变量不受影响
- `核异常 值错误 核作为 错误：` 里的 `错误` 仍按变量名处理，不会被替换
- 对照表新增「六、异常类型」一节

**中文模块导入**

- `核导入 工具` 现在能加载同目录的 `工具.xht`
- 支持 `核从 工具 核导入 甲`、`核导入 工具 核作为 工`
- 通过 meta path finder 实现，只认 `.xht`，不影响任何正常导入
- 找不到模块时的提示改为「.xht 模块要和主脚本放在同一目录」

**新增 3 个示例**

- `06_集合与文本.xht`：集合四则运算、包含判断、文本判断、对齐填充、
  切分合并、进制转换、编号遍历
- `07_类与对象.xht`：类定义、构造、继承、`核父类()`、类型判断、计数器
- `08_异常处理.xht`：分类捕获、`核作为` 绑定、`核最终`、主动 `核抛出`、
  `核否则` 分支

**关于页**

- 新增「查看最新版本与下载」链接，点击直接打开 GitHub 发布页

**测试**

- 内核 25 项（含 8 个示例全部跑通）、界面 98 项、对照表自检全部通过

## 0.0.3 详细说明

**对照表扩展**

- 按既有命名规律补 96 项：内置函数 +44、方法 +52、关键字参数 +2
- 用户已定名：`核布尔`(bool)、`核帮助`(help)、`核求和`(sum)
- 覆盖情况：关键字 35/35、内置函数 59/67、方法 78/80、关键字参数 6/6
- 刻意留空 10 项（中文说法易歧义或易变）：
  `ascii` `bytearray` `bytes` `classmethod` `compile`
  `memoryview` `property` `staticmethod` `casefold` `isascii`
- 新增 `测试/拟名.py` 记录拟名依据，`测试/自检对照表.py` 查重与冲突

**语法高亮修复**

- 加了 96 个新词后暴露出断词问题：`核全表` 被高亮成 `核全`+`表`、
  `核删属` 切成 `核删`+`属`、`核是字母X` 切成 `核是`+`字母X`。
  原因是高亮正则没有词边界。现给中文词加右边界与「前面不能紧贴点号」的约束，
  长词优先、不再把标识符切碎。

**运行错误提示**

- 把内置名当变量赋值（`核说 = 3`）后调用会报 `'int' object is not callable`，
  原本只显示通用提示。现追加一行线索，明确指出
  「变量「核说」覆盖了内置函数 print：源码里有 `核说 = …` 这样的赋值」。

**命名校正**

- `dir` 的拟名由 `核目录` 改为 `核列属`（更贴合「列出属性」的原意）

**测试**

- 内核 25 项、界面 98 项、对照表自检全部通过
- 自测里原用 sum/type/flush 当「未定义」样例，这些现已定义会误报，
  改用真正留空的 ascii/bytearray/casefold 验证

## 0.0.2 详细说明

**界面**

- 顶部去掉重复标题栏：原先 Windows 原生标题栏和自绘标题栏各显示一次
  「核工坊 v…」，现在标题只由原生标题栏承担，自绘条只留品牌图标、
  菜单按钮与搜索框
- 层次感收窄：深色下「窗口/编辑器/面板/面板2」原本跨四档明暗，拖分栏时
  像一层层叠起来的板子；现收为两档，明暗差降到 0.005
- 暗色文字可读性：行号对比度曾是 2.61（几乎看不清），注释 4.04、面包屑
  4.25 也偏暗；现分别为 4.95 / 5.28 / 7.15，全部达到 4.5 的可读标准
- 浅色主题同样修正行号、注释、面包屑与次要文字，并把纯白编辑器略收一点

**拖入**

- 拖放原排在窗口创建后 80ms 才启用，刚打开的那一小会儿拖入没反应；
  现改为立即启用并补一次重试
- 拖入时主动前置窗口（deiconify + lift + 短暂置顶），否则窗口被盖住时
  用户看不到任何变化，会以为「拖了没反应」
- 拖入失败会明确给出文件名，不再静默

**运行与输出**

- 运行程序时控制台只显示「程序结束」却看不到输出：读管道时进程刚结束、
  数据仍留在缓冲区，读到空就退出了。现改为读到连续为空才收工
- 停止后残留输出仍会写入控制台、与「[已停止]」交错；现先等读线程收工
  再关管道，并丢弃本轮残留队列
- 停止、退出、销毁三条路径原先各写一份清理代码且不一致，现统一为
  `_终止子进程`；退出改为统一走 `销毁`

**健壮性**

- 保存失败会弹模态框，自动化/批量场景下永久挂起；现只有用户主动保存
  （工具条、Ctrl+S、菜单）才弹框，其余只写状态栏
- 保存到不存在的目录会失败；现自动创建缺失目录
- 打开二进制文件会把乱码灌进编辑器；现用 NUL 检测拦下并提示
- 关闭文档后仍有高亮定时回调打在已销毁控件上，抛 TclError；现关闭时
  取消该文档的待执行高亮，并在高亮里检查控件是否还存在
- 拖放模块的窗口过程引用、回调列表、已启用集合从不清理，窗口反复开关
  会持续累积；现新增 `释放拖放` 并在销毁时调用

**工具**

- `核 转译 文件 输出.py` 误用（漏写 -o）时会静默只打印到屏幕；现给出提示
- 归档脚本支持 `--覆盖`（会先把旧版备份到 `_旧_vX.Y.Z`），不再要求手动删目录
- 文件关联优先指向打包好的 exe，机器没装 Python 也能双击打开
- 打包脚本在打包后自动让 exe 自检资源完整性，不通过即报错

**测试**

- 内核 25 项
- 界面 98 项（新增配色对比度、层次差、拖入前置、保存健壮性等检查）
